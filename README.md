# Avanço de Programação

Dashboard para acompanhamento semanal do avanço de obra, dividido por categorias (Preliminares, Obra Civil, Montagem).

Os dados ficam armazenados no Supabase. Qualquer pessoa pode visualizar, mas é necessário login para editar.

## Configuração

1. Criar um projeto no [Supabase](https://supabase.com)
2. Rodar o arquivo `avanco-programacao.sql` no SQL Editor do projeto
3. Criar um usuário em Authentication → Users
4. Preencher a URL e a chave anon no início do `avanco-programacao.html`
